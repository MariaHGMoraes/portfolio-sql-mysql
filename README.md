# SQL | MySQL — Estudos e Portfólio

Repositório dedicado aos meus estudos e projetos práticos de Banco de Dados utilizando MySQL.

Este espaço documenta minha evolução no aprendizado de SQL, reunindo conceitos, exercícios e aplicações desenvolvidos ao longo dos estudos.

## 📚 Conteúdos estudados

### 01. Fundamentos de SQL
- Introdução a bancos de dados relacionais.
- Categorias de comandos SQL:
  - DDL — Data Definition Language
  - DML — Data Manipulation Language
  - DQL — Data Query Language
  - DCL — Data Control Language
  - DTL — Data Transaction Language
- Tipos de dados e suas classificações.
- Restrições e propriedades das colunas.

### 02. Manipulação e estruturação de dados
- ALTER TABLE
- ADD COLUMN
- MODIFY COLUMN
- DROP COLUMN
- INSERT INTO
- UPDATE
- SELECT
- DESCRIBE

## 🛠️ Ferramentas utilizadas

- MySQL
- MySQL Workbench
- Git
- GitHub

## 🎯 Objetivo

Consolidar conhecimentos em SQL e desenvolver habilidades práticas em bancos de dados, construindo uma base técnica para minha evolução na área de Tecnologia e Dados.
