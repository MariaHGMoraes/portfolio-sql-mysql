# 📚 02 | Consultas SQL

Pasta dedicada aos exercícios práticos de consultas em bancos de dados relacionais utilizando SQL e MySQL.

Os arquivos reúnem consultas desenvolvidas durante as aulas do curso de MySQL do **Curso em Vídeo**, ministrado por Gustavo Guanabara, com foco na seleção, filtragem e organização de dados.

## 📋 Conteúdos estudados

### 01. SELECT — Parte I

- SELECT — Seleção de colunas e registros.
- FROM — Definição da tabela consultada.
- ORDER BY — Ordenação dos resultados.
- WHERE — Filtragem de registros.
- Operadores relacionais:
 - Igualdade (=)
  - Maior que (>)
  - Menor que (<)
  - Maior ou igual (>=)
  - Menor ou igual (<=)
  - Diferente de (!=)

- BETWEEN — Seleção de valores dentro de um intervalo.
- IN — Seleção de valores pertencentes a uma lista.

- Operadores lógicos:
  - AND
  - OR
